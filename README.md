# comm-analyzer

Analyzes how a user and Claude communicate across Claude Code session logs, and
maintains a data-derived working profile that keeps Claude's behavior tuned to
how the user actually works.

## What's here

| File | Role |
|------|------|
| `scripts/comm_analyze.py` | Parser. Reads `.jsonl` session transcripts and reports volume, terseness, speech-intent distribution, friction/affect signals, and token efficiency. |
| `agents/comm-analyzer.md` | Claude Code subagent. Runs the parser, interprets the numbers, and refreshes `comm-profile.md`. |
| `comm-profile.md` | Data-derived working rules (who the user is + friction-ranked rules + evidence). Regenerated by the agent. |

This folder is the versioned source. The live install lives under `~/.claude/`:

```
~/.claude/scripts/comm_analyze.py
~/.claude/agents/comm-analyzer.md
~/.claude/comm-profile.md
```

Copy files there to install/update.

## Usage

```bash
# current project (auto-detected from cwd)
python ~/.claude/scripts/comm_analyze.py

# a specific project log dir
python ~/.claude/scripts/comm_analyze.py "~/.claude/projects/<slug>"

# every project
python ~/.claude/scripts/comm_analyze.py ALL
```

Or, in Claude Code, spawn the `comm-analyzer` subagent ("analyze our
communication" / "update the comm profile") to run the parser and rewrite the
profile in one step.

## Model

Three axes of user messages:

1. **Speech intent** — single label, mutually exclusive. Priority:
   `redirect > info-question (WH / why) > imperative > probe > question > statement`.
   Command-phrased-as-question ("커밋해줄래?") counts as imperative (act dominates);
   a WH word ("삭제하면 어케됨?") makes it a question even with a command verb.
2. **Friction** — independent flags: `redo / wrong / broken / error`.
3. **Affect** — independent flags: `praise / frustration`.

Intent is single-label (no double counting); friction and affect are flags
(a message can carry several).
